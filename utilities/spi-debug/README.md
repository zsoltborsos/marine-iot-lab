# SPI Debug Utilities

Logic analyzer and oscilloscope debugging tools for SPI development.

## Contents

- **`spi debug1`** - Original debug notes from e-paper display development

## Usage

These are general-purpose SPI debugging utilities and commands that can be used with any SPI project, not just the e-paper display.

### Sigrok Commands

The `spi debug1` file contains sigrok-cli commands for capturing and decoding SPI signals using a Raspberry Pi Pico as a logic analyzer.
